# Sorrel Browser

A free desktop browser for web developers, made by [Sorrel Technologies](https://sorrel.technology). It runs on Chromium, so pages look and work the same as they do in Chrome, and the tools you use every day sit one click away in the sidebar.

## Download

Windows only for now. Get the latest installer, or any earlier version, from [Releases](https://github.com/intrusivecode/sorrel-browser/releases).

## What it does

- The new tab page lists the dev servers running on your computer. If a server is down, its tab waits and loads the moment the server is back.
- The Inspect panel shows speed timings, page weight by file type, the frameworks a site uses, and security headers checked one by one.
- Throttle to Fast 4G, Slow 4G, 3G or offline, run JavaScript in the page, and lay pages out at real phone, tablet and laptop sizes.
- A tracker blocker runs on every site. The browser sends no usage data, and your history, bookmarks and settings stay on your computer.
